# Vanguard 25K Desk

A free trade journal and position-size calculator for an Upcomers **Vanguard** futures account.

**Open it:** https://bikrambedi91-svg.github.io/vanguard-desk/

- It shows how much room you have before the daily drawdown, the trailing floor or the $375 max trade loss would end the account.
- It sizes every trade so that every limit holds, with slippage, fees and a safety buffer included.
- The journal covers setups, mistakes, emotions, grades, screenshots, a calendar and stats.
- Payout readiness covers qualifying days, the 20% best-day rule, per-payout caps and fees.
- You can install it on your phone: in Safari, Share → Add to Home Screen; in Chrome, Install app.

Your data saves in your browser. You can also sync it across devices through a private GitHub repository you own; see Setup in the app. Nothing is sent anywhere else.

This repository holds only the built site. It contains no journal data.
